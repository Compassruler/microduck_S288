# Microduck S288

基于宇树 S288 舵机的 Microduck 双足机器人个人制作与实验记录。

本仓库汇总采购清单、装配与接线记录、舵机实验、硬件参考资料和论文阅读笔记，记录从机器人装配、舵机参数辨识、零位标定到后续仿真与强化学习部署的开发过程。

## 项目概况

- **执行器：** 15 个宇树 S288 舵机。
- **主控：** RDK X5。
- **惯性传感器：** LSM6DSV16X 六轴 IMU。
- **主要工作：** 机械装配与接线、BAM 单摆参数辨识、软件零位标定，以及仿真与实机适配。

具体实验条件、结果与后续变化见实验文档和开发日志。

## 软件与本地资料管理

BAM 和零位标定软件各自使用独立的 Git 仓库，在对应软件目录内单独提交和更新。它们没有作为本仓库的 Git 子模块引入，克隆本仓库不会自动下载这两个软件。

以下本地目录由 [`.gitignore`](.gitignore) 排除：

| 本地目录 | 内容 |
| --- | --- |
| `个人开发/bam/` | BAM 源码、S288 适配及本地实验文件 |
| `个人开发/s288-calibration-studio/` | S288 零位标定软件源码 |
| `个人开发/S288零位标定工具_发布版_*/` | 零位标定软件的各版本发布包 |
| `个人开发/结构件/` | 机械设计、结构模型与打印件 |
| `开源资料/`、`申报材料/`、`课程汇报/` | 本地保留的其他资料 |

本仓库中的实验文档用于记录方法与结果；运行 BAM 或零位标定软件时，请使用各自项目的环境和使用说明。
