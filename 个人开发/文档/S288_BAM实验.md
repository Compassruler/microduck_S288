### 2.2 参数含义

| 参数 | 本实验含义 | 单位 |
|---|---|---|
| `mass` | 末端集中质量：砝码＋末端螺丝＋螺母，不含摆杆 | kg |
| `arm_mass` / `--arm-mass` | 摆杆总质量 | kg |

本轮沿用“均匀杆＋末端点质量”的 BAM 单摆近似：

```text
外部台架转动惯量 J = mass × length² + arm_mass × length² / 3
重力力矩 τg = -(mass + arm_mass / 2) × 9.80665 × length × sin(q)
```

螺丝、砝码等实际具有尺寸，本轮将其合并为末端点质量。模型中的 `armature` 是另行辨识的输出端等效附加惯量，不应把外部台架质量重复加进去。

- 2 个砝码、M4×60、1 颗螺母：100＋5.1＋0.8＝105.9 g。
- 3 个砝码、M4×60、1 颗螺母：150＋5.1＋0.8＝155.9 g。

## 3. 控制方式与零位

### 3.1 本轮控制口径

本文统一使用输出端物理量：

```text
τcmd = τff + Kp × (qtarget - q) + Kd × (ωtarget - ω)
```

本轮采集固定 `τff = 0 N·m`、`ωtarget = 0 rad/s`、`Kd = 0.02 N·m·s/rad`，因此：

```text
τcmd = Kp × (qtarget - q) - Kd × ω
```

驱动负责输出端与协议内部量之间的减速比换算及整数编码。调用采集程序时不再手工乘除减速比；离线模型会还原协议量化后的有效 Kp、Kd，不能将输入的十进制增益视为完全连续的有效增益。

这里的 `τcmd` 是控制模型请求的力矩；日志 `load` 是设备反馈的估算力矩，不是外接力矩传感器的测量值。

### 3.2 建立零位

将摆杆置于竖直向下位置，在官方调试助手中读取 `outputPos`，作为该装配的 `zero-offset`：

```text
日志中的摆杆角度 = outputPos - zero_offset
发送的输出端位置目标 = 轨迹角度 + zero_offset
```

本轮三种装配零位分别为 0.183885、0.171515、0.0690462 rad。它们是本次装配的记录，不是所有 S288 通用的零位。

当前驱动的 `outputPos` 来自转子位置经减速比折算；`ExPos` 是另一个输出端编码器的单圈读数，未展开、未校零。不能把两者未经处理直接相减当作统一误差，也不能随意互换用于控制和辨识。

### 3.3 轨迹与释放

四条轨迹来自 `bam/trajectory.py`，`amplitude-scale = 1`、`time-scale = 1`，正式采样名义时长均为 6 s。

| 轨迹 | 目标与作用 |
|---|---|
| `sin_sin` | 多频率正弦组合，覆盖不同速度和加速度 |
| `lift_and_drop` | 前 2 s 从 0 平滑移动到 −π/2，随后请求零驱动力矩 |
| `up_and_down` | 0 → π/2 → 0.8×π/2 的平滑轨迹 |
| `sin_time_square` | `sin(t²)`，频率随时间增加 |

轨迹是目标角度随时间变化的曲线；程序按实际时间采样曲线并持续发送目标，不是在一次实验中只发一个最终位置。样条插值属于官方轨迹定义，本轮没有再叠加自定义 `movetime`。

准备阶段保持首个目标约 1 s；结束时仍使能的轨迹按原流程逐步回零。准备和回零不计入正式日志采样。已释放的轨迹不会为回零重新使能。

`torque_enable = false` 时，当前驱动在 FOC 模式请求零 Kp、零 Kd、零前馈力矩。它不等于切断电源，也不保证摆杆自由落下；机械摩擦等被动作用仍然存在。因此，正常驱动阶段的 Kd＝0.02 不应在释放后继续作为位置控制阻尼发送。

### 7.2 误差定义与复算口径

下表为 **2026-10-21 使用当前模型参数和当前 BAM 原积分器做的只读复算**，不是从历史终端抄录的 `Best score`，也没有重新优化参数。

```text
角度 MAE = mean(abs(仿真角度 - 实测角度))
角度 MAE / ° = 角度 MAE / rad × 180 / π
```

比较的是“仿真预测与实测”的误差，不是“目标角度与实际位置”的跟踪误差。每条轨迹从第一个实测角度、速度开始，按其 Kp、Kd 和负载计算控制，使用模型拟合的指令延迟，不做周期性状态重置。

### 7.3 模型选择

M6 的总体 MAE 最低，但相对 M5 的改善很小：验证集约 0.00275°（0.13%），重复集约 0.00333°（0.29%）。因此保留 M6 供比较，当前采用参数更少的 M5 作为后续适配基线；这属于复杂度与效果的折中，不意味着 M5 的数值误差优于 M6。

当前样本不支持把这种很小的差异解释为统计显著优势，也没有统一的“低于某个角度就能上机器人”的合格阈值。模型选择还要看不同阶段的误差和最终任务表现。

## 9. 实验结论与应用边界

1. 本轮保留的 11 组、两轮 880 条数据已完成处理；M1–M6 参数文件均已生成，可用于当前 BAM S288 离线模型。保留不代表已经排除全部潜在机械异常。
2. 当前选用 M5。它在驱动阶段的表现优于释放阶段，但总体平均误差不能掩盖个别释放记录的大偏差。
3. 已确认部分释放后停滞没有外部阻挡。现有日志仍不足以独立确定机械摩擦、齿隙／传动变化、设备释放行为等因素各自的贡献，不能直接归咎于固定 Kd。
4. 当前 S288 执行器模型采用理想力矩源近似，没有显式建模力矩饱和、电流环动态、齿隙或温度变化；只用本次结果不能保证大负载、高温或不同舵机下的准确性。
5. 本轮固定 Kd＝0.02、前馈力矩和目标速度为零；尚未覆盖大范围改变这些控制参数后的响应。这些控制参数与 M1–M6 的摩擦模型参数是不同层次的量。
6. BAM 参数用于仿真，不写入舵机固件；也不等于已经选好了 Microduck 整机的最佳 Kp、Kd。
7. 下一阶段按计划先复现官方 Microduck RL 流程，再在相应训练／实机工程中接入 S288、新结构质量惯量和关节映射。现有实验数据及模型保留，不因整理本文而改写。
8. 如后续要验证释放工况或更换完好舵机后的适用性，优先做有针对性的对照试验，并记录硬件身份、温度、零位和实际释放指令；不自动把全部历史实验重做一遍。
